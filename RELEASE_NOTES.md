# Burglar 0.26.7 — Drafted Hanging Chad and Bloodstone in Balanced

- Burglar now offers the Multiplayer PvP version of a drafted Hanging Chad or Bloodstone when the active ruleset silently replaces the vanilla Joker. Previously neither version could appear in normal Balanced shops.
- This also applies to drafted Buffoon Packs and eligible Joker generators. True bans and custom cube copy limits still apply. Vanilla shops keep their original Joker IDs and odds.

Checked with 1,000 simulated shop Joker slots per ruleset per build using MultiplayerAPI/PvP 1.0.5 rules and mocked Balatro card creation. No live multiplayer playtest.

## Installing

Everyone should update to Burglar 0.26.7 and MultiplayerAPI/PvP 1.0.5 before starting a fresh draft. Lovely 0.10.0+ and Steamodded beta-1814a+ are still required. Replace the whole old Burglar folder; don't install two copies. Keep the current icon and manifest name when updating the existing cj-Burglar Thunderstore listing.

## Files

- `Burglar_v0.26.7_Standard.zip`: attach to your GitHub release; players extract the Burglar folder into Mods.
- `Burglar_v0.26.7_Standard_Thunderstore.zip`: upload unchanged to the existing cj-Burglar package.
- `Burglar_v0.26.7_GitHub_Source.zip`: extract and upload the contents of Burglar-source to the repository root. This is for development, not the recommended player installation.

See `docs/RELEASING.md` in the source ZIP for the upload steps.
