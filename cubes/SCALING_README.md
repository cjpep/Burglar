# Don't Worry Chat, We're Scaling

126 copies, 63 unique Jokers. Includes one Burglar, one Vagabond, one Turtle Bean, and one Mail-In Rebate.
Space Joker, Gros Michel, Popcorn, and Diet Cola are absent. All other proposed counts are retained.

## Select the cube

In Open draft (or Local development draft), click Draft pool until it shows
`dont_worry_chat_were_scaling.json`. The description shows the cube's display name.
Choose three packs for a standard four-player draft: 108 copies are drafted and
18 are left out. Four packs with four players requires 140 copies, so this cube
cannot support that setting. Everyone should install this same build.

## Design notes

Burglar trades away discards for hands: it helps hand-based plans but conflicts
with discard-based plans using Hit the Road, Castle, Faceless Joker, and
Mail-In Rebate. Those are alternative draft plans, not a promise
that every Joker works together. There are no additional balance cuts in this build.

Asteroids are excluded from normal consumable generation in Burglar runs using
the Balanced layer (including rulesets built on that layer). Other Balanced
changes remain active. Regular multiplayer games without a Burglar roster are
unaffected. This does not remove already-owned consumables from an existing save.
Start a new match to use the new cube and avoid any previously obtained Asteroids.

This is a design proposal, not a playtested balance guarantee.
